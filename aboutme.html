About

Christopher Vistal

I'm a software engineer in Tandag, Surigao del Sur, Philippines (UTC+8). For 5+ years I have designed, built, and maintained web platforms from start to finish, mostly in Laravel, Vue.js and Go, deployed on AWS or on an organization's own servers.

Since 2024 I have worked freelance. I built a law firm's case management platform solo, and a Google Drive-style file and submissions platform shared across the campuses of a multi-campus state university.

From 2021 to 2024 I was a software engineer for the Province of Surigao del Sur. I replaced paper and Excel with a civil-servant records platform, wrote an offline transcriber for confidential session recordings, brought the team onto Git and code review, and mentored three engineers.

I studied Computer Science at Surigao del Sur State University, now NEMSU (2015 – 2019), and interned there in 2018, building a faculty evaluation app used by 3,000+ students.

How I work

Habits drawn from the blog posts, each one learned on a real build.

  • Boring architecture one person can run

    A monolith on one EC2 instance served the law firm better than ECS or Lambda would have. The monolith is boring; the monolith ships.

  • Model the domain first

    Campus, department, team and person became first-class owners in the university hub. The platform is only as useful as the model underneath it.

  • Safe by default

    Explicit membership scopes on every read, policies as a second check, and client visibility whitelisted rather than blacklisted.

  • Ship into daily use

    The law firm kept practicing while we migrated, with no staging-only period. Rollouts have to work on day one.

  • Right tool for each job

    PHP for the app, Go for long-lived uploads and document signing, CTranslate2 when Whisper had to run fast on a CPU.

  • Leave the team stronger

    I moved a provincial team from FTP uploads to Git, pull requests and scripted deploys, and paired with three colleagues until they ran it without me.
